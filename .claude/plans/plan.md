# graftx 実装計画

設計ドキュメント: [docs/design.md](../../docs/design.md)

## フェーズ1: 基盤レイヤー

依存グラフの葉ノードから構築し、テスト可能な状態を常に維持する。

- [ ] `internal/fs` パッケージの実装
  - [ ] `Entry` 構造体の定義
  - [ ] `FileSystem` インターフェースの定義
  - [ ] `ReadDir` の実装（ディレクトリ先・アルファベット順ソート）
  - [ ] `Copy` の実装（ファイル/ディレクトリの再帰コピー）
  - [ ] `Remove` の実装
  - [ ] `Trash` の実装（macOS `~/.Trash`）
  - [ ] `Rename` の実装
  - [ ] `Create` の実装
  - [ ] ユニットテスト（一時ディレクトリ使用）
- [ ] `internal/pane` パッケージの実装
  - [ ] `Pane` 構造体の定義
  - [ ] `YankBuffer` 構造体の定義
  - [ ] カーソル移動（上下、クランプ処理）
  - [ ] ディレクトリ遷移（`h`/`l` に対応するロジック、カーソル復元）
  - [ ] ファイル選択（トグル、全選択、反転、解除）
  - [ ] ヤンク操作（選択中 or カーソル行をバッファに格納）
  - [ ] ユニットテスト（`FileSystem` モック注入）

## フェーズ3: コア機能

ユースケース「リポジトリ間コピー」を実現する。

- [ ] `s` キーによるリポジトリ選択
  - [ ] MainLoop一時停止 → fzf起動 → 再初期化の実装
  - [ ] 左ペインに選択リポジトリのファイル一覧表示
  - [ ] キャンセル時の状態復元
- [ ] ファイル選択の描画
  - [ ] `Space` 選択トグルのキーバインドと `*` マーク表示
  - [ ] `v` ビジュアルモード
  - [ ] `Ctrl+a` 全選択、`Ctrl+r` 反転、`Esc` 解除
- [ ] コピー操作
  - [ ] `y` ヤンクのキーバインドとステータスバー表示
  - [ ] `p` ペーストの実装
  - [ ] 同名ファイル確認ダイアログ（ポップアップペイン）
  - [ ] `P` 上書きペースト
